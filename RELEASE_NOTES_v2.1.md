# Brisket Session Analyser v2.1

## Theme
**Upload your probe file and let the software figure out the rest.**

## Added
- Automatic session classification
- Automatic pull detection for combined Cook + Hold files
- Detection confidence and explanatory reason
- Advanced manual pull-time override
- Calibration / Hold Test recognition
- Average, minimum and peak probe statistics
- One-file primary workflow

## Changed
- Removed the separate Cook and Hold upload workflow from the main experience
- Cook-only and Hold-only results are labelled as partial contributions
- Empty temperature bands remain hidden from the normal results view

## Notes
Automatic detection is an estimate and should be reviewed before relying on the final tenderness assessment.
