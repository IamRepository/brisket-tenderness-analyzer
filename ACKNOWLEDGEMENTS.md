# Acknowledgements

## Steve Gow

This application is based on the brisket rendering methodology developed and published by Steve Gow.

Steve Gow's work on brisket rendering, holding, and temperature-based tenderness estimation forms the foundation of the calculations used within this project.

Full credit for the underlying methodology belongs to Steve Gow.

## Independent Implementation

Brisket Session Analyser is an independent software project created to analyse probe temperature data and estimate brisket rendering and tenderness.

This application is not an official Steve Gow or Smoke Trails BBQ product and is not affiliated with, endorsed by, or maintained by Steve Gow.

## Important Note

All tenderness and rendering calculations are estimates.

Users should always validate results using traditional barbecue assessment techniques such as:

- Probe tenderness
- Slice performance
- Moisture retention
- Personal judgement and experience
